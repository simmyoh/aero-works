# Contributing

1. Open or choose an issue and keep the change focused.
2. Put learning material under the appropriate `src/content/tracks` folder.
3. Cite primary sources, record the applicable regulation or publication, and avoid copying copyrighted question banks.
4. Add or update tests, then run `pnpm test`, `pnpm lint`, and `pnpm build`.
5. Submit a pull request describing the learner outcome, source review, and validation performed.

Content changes should receive both subject-matter and editorial review. Questions should test one objective, use plausible distractors, explain the answer, and avoid ambiguity.
