# Part 107 content-source policy

The Part 107 learning track uses a closed source set supplied in the linked project folder. Study-guide statements, practice-question answers, explanations, and references must be traceable to one of these files or to a resource explicitly named inside `Resources_UAS-Recurrent-Non61.pdf`.

## Supplied files

- `Training - Learning Center Courses Content - FAA - FAASTeam - FAASafety.gov.mp4` - the detailed ALC-677 instructional modules.
- `Introduction - Learning Center Courses Content - FAA - FAASTeam - FAASafety.gov.pdf` - audience, objectives, training structure, recency, and § 107.73 knowledge areas.
- `Review - Learning Center Courses Content - FAA - FAASTeam - FAASafety.gov.pdf` - eligibility, recency, aircraft characteristics, exclusions, registration, crew roles, maintenance, waivers, emergencies, and reporting.
- `Glossary - Learning Center Courses Content - FAA - FAASTeam - FAASafety.gov.pdf` - course definitions and abbreviations.
- `Resources_UAS-Recurrent-Non61.pdf` - the approved external-source list.

The large source files are not copied into the public repository. The site exposes their titles and scope so learners can understand the provenance without redistributing the course package.

## Permitted linked resources

Only FAA or government resources named by the supplied resources PDF may extend the course material. These include 14 CFR Parts 48, 89, and 107; AC 107-2; the Pilot’s Handbook of Aeronautical Knowledge; FAA testing resources; FAA aeronautical charts and chart supplements; NOTAM/TFR resources; the Aviation Weather Center; and the other references listed in that PDF.

## Contribution rule

When changing Part 107 content:

1. Cite the supplied file and module/topic, or the filename and named linked resource.
2. Do not add a fact or test answer based only on general knowledge or an unlisted website.
3. Treat the supplied files as the study-content boundary, but verify live regulations before operational use.
4. Update the source-integrity tests when the source model changes.
